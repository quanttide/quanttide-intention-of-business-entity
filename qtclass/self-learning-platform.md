# 以学生为中心的自学平台工作愿景

量潮课堂的定位是一个自学工具。它是以学生为中心的学习管理工具，而不是以教师为中心的上课工具。

## 自学是教育体系的核心

无论是内部教学、开发者自学、给学生上课，还是校企合作课程，量潮教育体系的核心概念都是"自学"——混合式课堂、以学生为中心。

在以学生为中心的模式下，自学最重要，老师的作用是补充和讲解。因此，平台应该支持自学流程的法制化和标准化，让学生能够以更标准化的路径学习。

自学的核心是多练，练需要生产平台。生产平台本身就具有教育作用：教学有教学的侧重，生产有生产的侧重——生产要完成目标，教学要考虑人的发展。

## 双云架构：课程云与学习云

量潮课堂由两个组件构成：

- **课程云**：基于产教融合的课程研发体系，负责制作课程内容。这是量潮自创的体系。
- **学习云**：学习管理系统（LMS），负责管理学习进度。对应成熟的学习管理系统体系。

两个组件都置于"量潮课堂"之下。运行流程：课程云向学习云递交课程，学习云收集学习数据。工程上，把量潮课堂和课程云中的各种教学管理工具全部整合进学习侧，使量潮课堂成为一个真正的学习管理工具。

## 蓝图：学习过程的显性化

蓝图机制把本来由老师掌握的教学信息、进度信息直接展示给每一个学生。每个课时的学习脉络空前清晰，学生可以自主判断自己需要什么。

老师的区别退化为看一组学生的汇总。系统可以没有老师；即使有，老师也是辅助角色，更像支持性人员。

## 产教融合的正循环

产教融合在量潮课堂成为真正的商业模式：生产之中遇到的问题放进课堂，课堂带出的优质学生去处理产业的问题。一边是好问题的制造方，一边是好答案的设计方。

学生在学习过程中也可以参与课程的建设——这是真正的产教融合，也是真正的费曼学习法。这是量潮课堂要宣传的核心特性。

课程云还可以取外部优秀教程加工成课程：学习完之后，再把课程逐渐改成自己的体系，模仿学生如何参与到课程体系的改进之中。

## 商业模式：卖确定性，而不是内容

量潮课堂要卖的是某一种确定性，而不是内容。这在商业逻辑上与量潮数据一致。

模式是开源免费课程加付费服务：想读免费教程，在开源文档里读；想学习，到量潮课堂来。付费服务的价值来自精修加工（比免费版更精致）和附加服务（练习题、批改作业等）。

节奏上先开源，再找付费点，与整个体系保持一致。先有流量，才有增值付费的空间。

社区贡献采用等价交换：以视频单元为最小单元，接受开源社区的贡献，用各种代金券、优惠券作为激励和补贴。

## 团队层面的教育服务

团队层面可以统一数据，从"量潮课堂"或"学习营"一侧展示成员在团队中的学习情况——在团队层面提供教育服务。

学习云因此有一个额外关键作用：显性化学习情况，以及显性化组织对成员的教育工作。前提是生产体系和学习体系高度打通。

## 起步路径

1. 整合内容制作工具链，特别是图、视频等生产工具
2. 用 HTML 生成教学原型，或生成数据后套在客户端壳上学习——只要内容能学、学得下去，它就成立
3. 用相对陌生、从 0 开始学的内容生成蓝图试效果（如用开源智能体工程资料做初级版课程）
4. 基础数据就绪后，学习云的开发会顺畅——课程云递交课程、学习云收集学习数据的链路随之跑通

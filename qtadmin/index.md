# 量潮管理后台工作愿景

量潮管理后台（qtadmin）是企业治理思想和制度的平台化——展示的不是功能，是治理方法。

## 定位

qtadmin 承载量潮的治理思想：议事怎么设计（delib）、战略怎么发现（strategy）、资产怎么管理（asset），以系统化的方式展示和执行。视角首先是秘书处的管理视角。

与量潮云分工：量潮云是所有人都能用的生产工具；qtadmin 剥离所有生产工具，是治理思想在系统侧的载体。

## 核心目标

封装我们独特的思考方式：从实际流程中提取模式，找到数据，让 AI 学习，设计程序封装。知识提炼链（从沟通语形成共识）是第一步落地——招聘与课堂的政策都从这条链路沉淀。

## 内部资产管理

内部资产按三层建模：原始数据（assets）、人类分析（data）、总结知识（docs）。每一个人一个 workspace。

工作案例是资产提炼的起点：CEO 介入管理当作投资行为建立案例，AI 总结记录，从案例提炼工作札记、工作手册与工程标准。

## 起步路径

从导出飞书和 GitHub 的数据开始，建立组织层面的分析工具。先数据建模，再二次抽取。

## 演进方向

优惠券和代金券是未来代币的前身。体系能跑的前提是产能突破瓶颈——不靠堆人，靠系统。

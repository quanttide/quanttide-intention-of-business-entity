# 量潮咨询工作意图

量潮咨询重启，采取自己的方式：它作为一个**总控制台**，负责回答我们的总体目标（例如实现规模化增长），并将其分解为各板块的职责。

## 总控制台分解

| 板块 | 职责 |
|------|------|
| 量潮数据 | 负责数字化 |
| 量潮云 | 负责产品化 |
| 量潮课堂 | 负责人才培养的规模化 |
| 管理后台 | 负责创始人经验的产品化 |
| 招聘 | 负责规模化，以及将成本变成收入化 |
| 量潮咨询 | 负责总体把握，处理其他无法被上述部分概括的内容 |

## 自己咨询自己

通过这套方案去指导整个团队的动作，把咨询流程的打磨变得更加透明，业务协同变得更加透明，最终体现出我们的盈利方式和市场结构长什么样子。

同时也解决客户看不到这个服务的问题——通过内部服务的方式去打磨这个流程。

## 流程显性化

让流程显性化，至少能够给客户展示一个完整的案例。哪怕这个案例只是个内部案例，也比外部案例展示不出来要强。等我们有更好的外部案例时，再一起展示出来，或者把它替换掉。

## 定位

不指望它现在商业化，把它作为一个跟招聘一样的辅助工具。这个品牌挂着，说不定就有商业化空间了，没有也没有关系。跟云一样，我们聚焦于数据和课堂商业化平台。
